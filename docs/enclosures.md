# Enclosure studies

Study → Arpeggio sequences offers **4-note enclosures** and **5-note enclosures** in every tier, using the existing fixed-region or manual position route. The same exercises are available under Exercises → Chromatic language. Counts include the final target. Pattern offsets are semitones relative to that target, with `0` displayed as “target”.

Each length has four curated patterns. Select all core chord tones or a structural tone by its ordinal within the current chord. Altered/suspended tones retain the chord's spelling; backing extensions are not separate targets. Changing the starting direction reverses the order of target pitches, while the selected approach formula remains unchanged. Legacy enclosure exercises and saved selections remain supported.

There is no universal number of possible enclosures. With exactly four allowed approach pitches (two above and two below), no repeated approaches, both sides represented, and the target fixed last, there are 24 ordered four-note cells and 24 ordered five-note cells. Requiring the last approach to be a semitone from the target reduces each count to 12. Other pitch sets, repetitions, diatonic neighbours and rhythms produce different totals. The app presents selected musical patterns rather than all permutations.

New studies insert rests so targets land on quarter-note beats at each subdivision. These are not necessarily bar downbeats. A complete cell must fit within its own backing-chord slot; it is never truncated or assigned to the outgoing chord. A slot with no complete playable cell is a rest with a timing/range warning. Longer slots or faster subdivisions provide more room. Approaches stay inside the selected fret region; no pitch is silently substituted to force a cell to fit.

Verification: key/quality/pattern/target/direction matrix, physical pitch/fret validity, extended-chord target filtering, subdivisions and unequal/short harmonic slots, single-chord score duration, Study integration and browser controls/favourite restoration/mobile layout.
