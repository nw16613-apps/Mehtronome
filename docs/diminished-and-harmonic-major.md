# Diminished and harmonic-major integration

Added Half–whole diminished and Whole–half diminished as eight-note scales,
and Harmonic major with its seven modes: Harmonic major (Ionian ♭6), Dorian ♭5,
Phrygian ♭4, Lydian ♭3, Mixolydian ♭2, Lydian augmented ♯2 and Locrian ♭♭7.
All use the existing chord-first grouped guide picker, chart storage, diagrams,
notation, exercises and backing engine; there is no separate workshop.

The new chord types are Dominant 7♯9 with natural fifth, Dominant 13♭9,
Dominant 7♭9♯11 and Diminished major 7. They have explicit formulas, recommended
strict-compatible scales and dedicated sustained-harmony voicings. Half–whole
supports dominant flat-nine/sharp-nine/sharp-eleven/natural-thirteen colours;
whole–half supports diminished seventh and diminished-major seventh harmony.
Harmonic major's fifth mode supplies the seven-note 13♭9 option.

Eight-note scale names use explicit degree spellings, retaining both adjacent
thirds in half–whole and diminished-seventh spelling in whole–half. CAGED views
use root-anchored fret windows for the symmetric scales rather than claiming a
major-scale parent fingering. Harmonic-major modes share their parent geometry.
No alternate G-string endpoint is trimmed from the eight-note windows.

Scale groups, interval/step patterns, alternating-note arpeggios, chord-tone
stacks and octave arithmetic now use the actual collection length. Continuity
and range turns remain intact across seven/eight-note chord changes. Scale-derived
triad/pentatonic suggestions and backing neighbours also include the eighth tone.
The harmony reference displays eight alternating-note tetrads for diminished.
Material labels use three/four/five-note stacks if a progression contains an
eight-note scale: a five-note alternate-step stack repeats the root at the octave,
so it is not called a diatonic ninth chord. Ordinary seven-note exercises retain
their existing labels. Unsupported automatic modal-vamp shortcuts stay hidden;
new guides can be used in any editable chord chart.

Validation covers every tonic and CAGED frame, eight-note spellings and step
sizes, a golden group spanning the eighth degree, octave wrapping, all nine new
guides, strict chord matching, source palettes, mixed seven/eight-note progressions,
range turns and backing voices. Browser checks cover grouped menus, references,
CAGED diagrams, notation playback, saving/reloading mixed-scale charts and mobile
layout. Existing seven-note pattern/continuity, voicing and scale tests pass.
