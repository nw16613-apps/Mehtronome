# Tiered fretboard study pathway

The first **Study** tab organises existing charts, CAGED positions and exercise material. It opens on launch; Progress retains saved setups and tracking. No beginner prompts, readiness gates or new exercise generators are added.

1. **One mode · one key:** a chosen chord quality and mode, across the neck.
2. **Changing keys:** the same sound through interval root orders, including minor thirds and the circle of fourths. An interval cycle uses its actual distinct-root count; All 12 roots visits every pitch class. Every slot keeps the chosen quality and mode.
3. **Mixed qualities & modes:** common turnarounds and progressions, including altered-dominant, minor, backdoor, tritone and secondary-dominant patterns, with a chart key and editable chord-scale guides. Key movement offers Single key or Circle of fourths, which transposes the complete progression through all 12 keys.
4. **Standards & songs:** existing credited jazz-standard practice charts, original complete forms, current chart and browser-saved repertoire. Source durations, split bars, sections and credits are retained. Transposition and edits affect the working copy, not the saved source.

Every tier offers **Fixed region** or **Manual positions**. Fixed region uses the existing automatic CAGED route near the chosen region. Manual positions assigns each chord slot independently; Set every position to is a bulk shortcut. **Passes** repeats the chart with separate position assignments, allowing the same material in successive regions and arbitrary transitions. The existing 128-slot limit bounds the number of passes. Existing scale/arpeggio traversal and pattern-start choices are retained.

**Chord first / Mode first** uses reciprocal compatible choices. In single-quality studies it defines the pair for every root. In mixed patterns and songs it edits only the selected chord, retaining that slot’s root and duration. Clicking a chart card also selects that slot for editing. Workflow changes alone do not rewrite imported guides. All mode families are available; strict compatible chord choices include triads, sevenths and extensions.

Material includes the existing scales, core arpeggios, scale sequences, arpeggio sequences and CAGED chord voicings. **Load study** replaces the working chart and selects its route and material, opening Exercises or Fretboard for chord voicings. Undo retains the previous chart, key and route. Loading retains tempo, backing style and mixer levels, enables backed exercise looping and does not start playback. Matching Study cards highlight the current chord one at a time during playback; replacement/edit controls lock while playing.

The compact loaded-study bar links Chart, Fretboard, Exercises and Study. Setup changes mark the loaded session as modified. Reload study restores its captured chart and route; ending study navigation leaves the chart in place. Browser-saved Study choices and optional manual Studied marks are independent of the old checklist. Marks identify actual harmony, material, duration and route, rather than unused controls. Legacy Dorian pathway selections migrate to the new organiser. Saved mixed-pattern Tier 2 drafts now open on the corresponding Tier 3 progression; existing working charts remain intact.

Validation: 45 targeted model/regression checks and seven Study browser workflows pass, with a successful TypeScript/Vite build. Coverage includes all mode/chord workflows, twelve transposition roots, exact interval cycles, single-quality Tier 2 harmony and mixed Tier 3 patterns, independent selected-chord edits, all-tier manual routes, repeat passes, original chart timing/credits and malformed storage. Browser checks cover loading, preserved sound settings, fixed/manual routes, saved/current charts, Undo, playback highlighting, persistence and desktop/phone layouts. Existing generator, arpeggio-start and position-route regressions are also checked. Audio sounds and backing DSP are unchanged.
