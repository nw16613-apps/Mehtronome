# Exercise ending bar

The displayed and playable exercise appends one bar after the generated pattern. The ending uses the nearest different core chord tone through the seventh of the opening chord, with that chord's spelling and altered/suspended/sixth tones. The ending must move to a different sounding pitch, even if the preceding note is already a chord tone. A unison on another string is excluded too. If the resolution board contains no different core pitch, leave the plan unchanged rather than append a repeated-note ending. Equal pitch distances prefer a root, then the existing string and the lower pitch. When the opening harmony matches the final harmony, keep the final assigned CAGED board. Otherwise choose a real opening-chord CAGED position near the final fret region and use its notes, labels and diagram; do not filter the old chord's scale and accidentally omit valid resolution tones. Never invent a fret outside the chosen board.

The ending is one duration-aware event. In 4/4 it is a whole note; other meters use ordinary note values and ties as needed. Notation, TAB, SVG export, selection, audition and the playback cursor share its index and pitch. The audio buffer and release use the full bar duration, including slow tempos beyond the ordinary short-note buffer cap.

Append the ending after bar alignment and any existing complete-chart repeats. Preserve the generated pattern events and groups without alteration. Keep the ending out of editable chord/position route cards: it is an uneditable return to the opening harmony, using the nearby resolution position.

Exercise accompaniment uses a private custom-progression copy of the displayed slot durations and returns to the first displayed/played chord for the ending, including its scale guide and slash bass. Wrapped loops resolve to their first played chord. The loop starts the exercise again after that bar; one-shot playback finishes after the full bar. This copy preserves slash bass and scale pitch collections and never writes to the user's chart or saved progression. Held-chord studies use the same duration-aware plan path.

Verification covers nearest-pitch choice, board bounds, unchanged pattern/chart data, all rhythms, representative progressions/keys/positions, wrapped chart loops, multiple meters, whole/tied-note rendering, exact audio durations, actual engine chord timing, export, phone layout and backed playback through the ending.
