Different guitars.
Different bass recordings.

The current arranger plays exactly the same notes, timing and articulations in both versions. Only the named instrument’s recordings change. Start with Solo to hear the source, then In the band to hear the balance.

These are candidates for you to judge. The app’s normal sounds have not been replaced. Shinyguitar is a steel-string archtop, not a nylon guitar; this first audition tests electric guitar tones. Growlybass has a forceful pluck; Sneakybass is a separate, softer upright recording session.

All three candidate libraries are CC0 from Karoryfer Samples. Two independent takes per sampled note/layer are used here. This audition uses ordinary sustained recordings; recorded slides, hammer-ons, palm mutes and release triggers are not implemented.

Solo pairs are matched in integrated loudness using constant gain. In the band, that source correction is applied to the candidate instrument; every other stem is identical. Both mixes then receive the same fixed gain. No compression, limiting or harmonic repair.
