Try a different upright bass.

Compare the previous Sneakybass recordings with two new acoustic double-bass libraries. Each plays the same notes, timing, articulation and tone processing. Start with Solo bass, then hear it In the band.

VSCO is now the app’s default upright bass. These clips preserve the original source audition.

VSCO 2 CE: solo contrabass pizzicato by Versilian Studios. D. Smolken Double Bass: 1958 Otto Rubner bass, a separate earlier recording library. These are acoustic alternatives; their character differs from the previous quiet Sneakybass session.

Both candidate releases are CC0. Original pitch maps and velocity regions are retained; measured sample tuning is corrected. Two recorded takes per zone. This compares ordinary plucked notes, without added slap/noise triggers or simulated slides.

Solo clips use fixed gain to match loudness. Band clips apply that bass correction while retaining identical other instruments and a common overall gain. No additional compression or EQ is used.
